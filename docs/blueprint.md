# **App Name**: EcoAssess AI

## Core Features:

- Project Proposal Submission: Allow users to submit new infrastructure or development projects with details like title, type, location, and description.
- AI Sustainability Evaluation: Evaluate the project’s sustainability using an AI tool, classifying it as Sustainable, Moderate, or Unsustainable, based on frameworks like UN SDGs.
- Actionable Improvement Suggestions: Generate 2-3 actionable suggestions to improve the project's sustainability, such as alternative approaches or modifications.
- Detailed Sustainability Report: Provide a detailed report including sustainability score, environmental impact breakdown (water use, biodiversity loss, CO₂ estimate), and suggested next steps.
- Project History Dashboard: Display previously submitted projects in a scrollable list with key details like title, type, location, sustainability rating, and timestamp.
- Firestore Integration: Store submitted projects, AI analysis results, and timestamps in Firestore.

## Style Guidelines:

- Primary color: Forest green (#388E3C) to evoke sustainability and nature.
- Background color: Light beige (#F5F5DC) for a clean, neutral backdrop.
- Accent color: Earthy brown (#A1887F) for highlights and calls to action, complementing the natural theme.
- Body font: 'PT Sans' sans-serif for a humanist, modern look, easy readability and functional feel.
- Headline font: 'Playfair' serif for an elegant, fashionable feel for section headings.
- Use clean, minimalist icons to represent project types and sustainability metrics.
- Implement subtle fade and slide animations when displaying new results and suggestions for a smooth user experience.
